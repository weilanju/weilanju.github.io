# Design Handbook (v1.2.1, English)

`design_handbook_v1.2.1_English.pdf`

The working design document for the whole project: object dictionary, identity constraints,
the three layers (price / value / information), the five information-media interfaces, PIT rules,
and — deliberately — the module that is **specified but not run**: the order book and matching
engine (Section 14).

v1.2.1 corrects four issues found when the handbook was checked against the reasoning notes
(`empirical/full_reasoning_notes_v2_en.html`): the mislettered subsection order in Section 23B,
the duplicated values for same-stage co-movement between text and table, the 37- vs 40-company
wording in Section 24A (37 have complete 750-day histories of the 40 priced), and it adds
Section 23C with the analyst-diffusion event-study results. The empirical style table (kurtosis
7.72, lag-1 autocorrelation −0.0158, |returns| autocorrelation at lag 1 = 0.1894) now matches
the reasoning notes.

It is kept here because it is the honest record of what the system does and does not claim to do.
If anything in the code or the statements of purpose seems to claim more than this handbook allows,
the handbook is the authority.
